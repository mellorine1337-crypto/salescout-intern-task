# SaleScout — автоматическое управление ценами

Тестовое задание web-разработчика: мини-версия прайс-бота для продавцов Kaspi.kz. Проект написан на **TypeScript**, с **Express API**, **React + Vite** и тестами **Vitest**.

## Возможности

- Рассчитывает рекомендуемую цену с учётом конкурентов в наличии, шага и минимального/максимального порога.
- `POST /reprice` принимает массив товаров и возвращает массив результатов в исходном порядке.
- Веб-интерфейс показывает SKU, название, старую и новую цену, изменение и причину расчёта.
- Поиск по каталогу, фильтрация по причине, редактирование исходных JSON-данных, экспорт CSV.
- Валидация данных API, тесты бизнес-логики и HTTP-эндпоинта.

## Запуск

Требуется **Node.js 20+** и npm.

```bash
npm install
npm run dev
```

- Интерфейс: http://localhost:5173
- API: http://localhost:3001
- Health check: http://localhost:3001/health

Для раздельного запуска:

```bash
npm run dev:server
npm run dev:client
```

Проверка и сборка:

```bash
npm test
npm run typecheck
npm run build
```

## Пример API

```bash
curl -X POST http://localhost:3001/reprice \
  -H 'Content-Type: application/json' \
  --data-binary @data/products.json
```

Результат соответствует `data/expected.json`. При передаче не-массива или некорректного товара возвращается `400` и JSON с сообщением об ошибке. Пустой массив допустим и возвращает `[]`.

## Правила ценообразования

1. Отбираются только конкуренты с `inStock: true`.
2. Если доступных конкурентов нет, устанавливается `maxPrice` (`NO_COMPETITORS`).
3. Иначе выбирается минимальная цена `best` и вычисляется `Math.floor(best - step)`.
4. Если кандидат ниже `minPrice`, возвращается `minPrice` (`AT_MIN`). Если выше `maxPrice`, возвращается `maxPrice` (`AT_MAX`). Иначе возвращается кандидат (`UNDERCUT`).
5. `myPrice` не влияет на расчёт и возвращается как `oldPrice`.

Важная деталь: **равенство** минимальной или максимальной границе означает `UNDERCUT`, а не `AT_MIN`/`AT_MAX`.

## Структура

```text
src/
  pricing.ts         # чистая функция calculatePrice — контракт автотестов
  types.ts           # типы Product, Competitor, PriceResult
  server.ts          # Express, проверка входных данных, /reprice
  index.ts           # запуск HTTP-сервера
  pricing.test.ts    # модульные тесты
  server.test.ts     # тесты API
web/
  App.tsx            # интерфейс React
  main.tsx           # точка входа React
  style.css          # стили интерфейса
data/
  products.json      # примеры входных данных
  expected.json      # эталонный результат
```

### Архитектура

`calculatePrice` — чистая функция без I/O и побочных эффектов, расположенная строго в `src/pricing.ts` с именованным экспортом. HTTP-слой валидирует входные данные, вызывает её для каждого товара и возвращает результат. React получает результаты исключительно из API, а не рассчитывает цены самостоятельно.

## Проверка вручную

Запустите `npm run dev`, откройте страницу и нажмите **«Пересчитать цены»**. Все шесть товаров должны получить цены и причины из `data/expected.json`. В «Редактировать данные» можно вставить свой массив товаров.

## Переменные окружения

- `PORT` — порт API, по умолчанию `3001`.
- `CLIENT_ORIGIN` — разрешённый CORS origin, по умолчанию `http://localhost:5173`.

Для разработки Vite проксирует `/reprice` и `/health` на порт 3001. Если меняете порт API, обновите также прокси в `vite.config.ts`.
